# Idées post-v1.0 — Index

Nouveautés imaginées après la rédaction de la roadmap. Chacune a maintenant sa version dans `docs/roadmap.md` et un fichier `docs/versions/vX.Y.md` au statut **À valider** : Claude Code ne commence aucune de ces versions tant que l'utilisateur ne l'a pas détaillée et validée.

## Quand une version est validée

Reporter le détail de ses fichiers d'idées dans `docs/versions/vX.Y.md` (jalons, critères de fin, tests obligatoires), passer son statut à « Prêt » dans le fichier et dans la roadmap.

## Règles qui s'appliquent

Toutes les règles de `CLAUDE.md` restent valables : contenu en packs RON, tout réglable ou désactivable, profil DS à 30 FPS et ≤ 2 Go, textes en fr/en/lol, **aucun lore écrit par Claude** (`[LORE À ÉCRIRE]`), noms propres en latin marqués `[NOM À VALIDER]`.
