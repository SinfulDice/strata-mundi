# Contribuer à Strata Mundi

Merci de votre intérêt !

## Issues : bienvenues

Les issues sont ouvertes à tous. Trois modèles sont proposés :

- **Bug** : quelque chose ne marche pas comme prévu.
- **Plantage** : le jeu s'est fermé brutalement. Joignez le rapport du dossier `crash-reports/` (le bouton « Signaler ce plantage » du jeu pré-remplit l'issue).
- **Idée** : une suggestion de contenu ou d'amélioration.

Écrivez en français ou en anglais.

## Pull requests : pas pour l'instant

Le projet est développé par un auteur unique et son assistant, selon une feuille de route précise (`docs/roadmap.md`). **Les pull requests extérieures ne sont pas acceptées pour l'instant** ; elles seront fermées sans fusion. Ouvrez plutôt une issue pour proposer votre idée.

Le modding sera ouvert à tous en v1.1 (dossier `mods/`, scripts Lua).
