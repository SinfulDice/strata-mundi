    /seed

    Shows the world seed.

    Run by the server.

    Description

    /seed shows the world seed: the little secret code from which the whole terrain was calculated. Same seed, same world, every time.

    Syntax

    /seed, with no argument.

    Examples

    • /seed: the console answers with the seed, for instance the word you typed when creating the world.

    Behaviour

    Run by the server. It's the only command available in every game mode: knowing your seed isn't cheating. If you typed some text as the seed when creating the world, that text is shown; otherwise, it's the randomly chosen number.

    Tips

    Share your seed with your friends: by creating a world with the same one, they'll get exactly the same landscapes, down to the block.

    Discovery in game

    The seed is chosen on the "New world" screen (leave it empty for a random one). /help seed recalls the command.
