## Description

`/help` is the console's cheat sheet: it lists every available command, with its syntax and a one-line explanation. Lost? Always start here.

## Syntax

- `/help`: shows every command.
- `/help <command>`: shows only the one you asked for (without the slash).

## Examples

- `/help` for the complete list.
- `/help time` to remember the time keywords.

## Behaviour

The command is handled directly by your screen, without going through the server, and answers in the language chosen in the options. It works in every game mode. An unknown command name simply returns nothing.

## Tips

Type `/help ` then press Tab: the console completes the command name for you.

## Discovery in game

Open the console with T or /: if you send an empty line or an unknown command, the answer reminds you that `/help` gives the list.
