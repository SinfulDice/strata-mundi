## Description

`/help` est le pense-bête de la console : il liste toutes les commandes disponibles, avec leur syntaxe et une phrase d'explication. Perdu ? Commencez toujours par là.

## Syntaxe

- `/help` : affiche toutes les commandes.
- `/help <commande>` : n'affiche que celle demandée (sans la barre oblique).

## Exemples

- `/help` pour l'inventaire complet.
- `/help time` pour se rappeler les mots-clés de l'heure.

## Comportement

La commande est traitée directement par votre écran, sans passer par le serveur, et répond dans la langue choisie dans les options. Elle fonctionne dans tous les modes de jeu. Un nom de commande inconnu ne renvoie simplement rien.

## Conseils

Tapez `/help ` puis appuyez sur Tab : la console complète le nom de la commande à votre place.

## Découverte en jeu

Ouvrez la console avec T ou / : si vous validez une ligne vide ou une commande inconnue, la réponse vous rappelle que `/help` donne la liste.
